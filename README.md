# scroll-jitter-fix

## Dependencies

System wide installation of the python evdev and uinput libraries

### Arch linux

```bash
# Using paru
paru -Sy python-evdev python-uinput

# using yay
yay -Sy python-evdev python-uinput
```

### Ubuntu and Debian

```bash
sudo apt install python3-evdev python3-uinput
```

### Fedora

```bash
sudo dnf install python3-evdev python3-uinput
```
